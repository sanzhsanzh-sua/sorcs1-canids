Структурная биоинформатика SorCS1 в трёх группах: фенек (n=10), лисы Беляева
(5 ручных / 4 агрессивных), домашние собаки + волки (20 из 722-геномного набора).

## Главный вывод

SORCS1 на белковом уровне **практически инвариантен**. Единственная подтверждённая
кодирующая замена — **S568N** (нумерация dog X5; человек Q8WY21 = 564; лиса X2 = 574):

- фиксирована у фенека **и у рыжей лисы** -> различие рода *Canis* (S) vs *Vulpes* (N),
  а не признак, уникальный для фенека; у человека в этой позиции T;
- **валидирована** пересчётом из BAM фенека: 8/8 образцов с покрытием, ~19 ридов,
  100 % альт-аллеля, 0 референсных аллелей, обе цепи (см. summaries/S568N_validation.md);
- сидит на поверхности 10-лопастного β-пропеллера VPS10p, за 5 остатков до
  Asp-box повтора 4; по гомологии с комплексом SorCS2–NGF (PDB 6FFY) эквивалентный
  остаток SorCS2 (540) находится в футпринте связывания лиганда, 3.3 Å от NGF
  -> замена попадает на предсказанный лиганд-контакт;
- химически консервативна (S/T/N) -> это тестируемая гипотеза о сдвиге
  лиганд-связывания β-пропеллера между родами, не доказанный эффект.

**Ручные vs агрессивные лисы Беляева:** кодирующих различий в SORCS1 НЕТ
(7 вариабельных кодонов, все синонимичные; мощность мала — n=5+4, ~3x).

**Оговорки:** N-конец SorCS1 (остатки 1–190: сигнальный пептид + первые лопасти
пропеллера) отсутствует в CanFam3.1 и не оценён для фенека/собак; ~10–13 % CDS
(пул) и ~45 % (подгруппы лис) не покрыто; структуры SorCS1 не существует —
только AlphaFold + гомология SorCS2.

## Воспроизводимость

Пайплайн пересобран заново (2026-09-10). Рабочая директория ~/Desktop/sorcs1_work/
восстановлена: скачаны хромосомы VulVul3, построены модели-GFF (miniprot),
пересчитаны VCF (bgzip/tabix/norm), консенсусы, выравнивания MAFFT, каталоги
вариантов. Все числа совпали с исходным прогоном.

ПРИМЕЧАНИЕ по собачьей группе (важно, было расхождение — исправлено).
Удалённый срез 722-геномного VCF Plassais et al. (NHGRI, регион ~52 МБ из-за
722 колонок генотипов) 2026-09-10 скачивался крайне медленно и рывками.
Фоновый скрипт finish_dog.sh в итоге собрал `dog722.norm.vcf.gz`, но из
**неполных** байт региона — реально скачанные данные покрывали только
`NC_006610.3:18 614 067–18 738 496` (~58% региона; ген SORCS1 — до 18 933 005,
т.е. без остатков ~191–400). Каталог вариантов, пересчитанный с этим файлом,
из-за этого тихо потерял 1 кодон и мог давать фиктивные «референс, покрытие
высокое» для собачьих групп там, где данных попросту не было.

Это замечено и исправлено: таблицы/последовательности/выравнивание в этой
папке взяты из ПОДТВЕРЖДЁННОГО ПОЛНОГО среза (весь ген, все 26 экзонов CDS,
18 622 295–18 933 005) — того же, что и в первом прогоне пайплайна:
  - tables/sorcs1_variant_codons_canfam31.tsv — 29 вариабельных кодонов,
    2 миссенс (S568N + полиморфизм S625N);
  - sequences/groupcons_canfam31.faa — dog-строки достроены из полной таблицы
    + референса CanFam3.1 (village: 1 отличие = S625N; wolf: идентичен
    референсу; помечены "reconstructed" в заголовке FASTA);
  - sequences/sorcs1_groups_plus_refs.aln — полное выравнивание всех 5 групп +
    4 референса, перепроверено: dog_village/dog_wolf = S, fennec/red fox = N,
    human = T в позиции S568N; dog_village 99.9% id к референсу (S625N),
    dog_wolf 100.0%.

Неполный сырой VCF из этого захода сохранён отдельно как
vcf/dog722_PARTIAL_18614067-18738496.vcf.gz с пояснением в vcf/README_PARTIAL.txt —
он НЕ использовался ни для одной цифры в tables/ или sequences/. Если нужен
полный сырой срез как файл — команда в том README, выполняется за ~68 с,
когда сервер NHGRI не троттлит.

Исходные данные на рабочем столе целы: fennec_data/, village_dogs_data/,
belyaev_fox_data/.
